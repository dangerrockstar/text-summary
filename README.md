# Interview Analyzer 🔥

Auto-discovers topics from interview notes without any manual keywords!

## 🚀 Quick Start

```bash
# 1. Clone & Install
git clone <your-repo>
cd interview_analyzer
pip install -r requirements.txt

# 2. Run
streamlit run app.py
```

## ✨ Features
- ✅ **Zero keywords** - Pure semantic clustering
- ✅ Auto-detects topics like Regex, Git, System Design
- ✅ Shows mention frequency
- ✅ Expandable examples
- ✅ Works with any interview notes
